# Components

Each family is one file, `<copy>/<family>/<family>.rx`. Read the family's own reference before using it.

| Family | What it is | Reference |
| --- | --- | --- |
| Accordion | A set of collapsible panels with headings. | [accordion.md](accordion.md) |
| Alert Dialog | A dialog that interrupts to ask for a decision. | [alert-dialog.md](alert-dialog.md) |
| Autocomplete | A text input that suggests what to type. | [autocomplete.md](autocomplete.md) |
| Avatar | A picture of a user, with a fallback while it loads or when it fails. | [avatar.md](avatar.md) |
| Button | A button that can stay focusable while disabled, or be another element. | [button.md](button.md) |
| Calendar | A month grid for choosing a day, or a range of days. | [calendar.md](calendar.md) |
| Checkbox | A native checkbox that can be styled whole, with an optional indicator. | [checkbox.md](checkbox.md) |
| Checkbox Group | A set of checkboxes that share one value: the list of the checked ones. | [checkbox-group.md](checkbox-group.md) |
| Collapsible | A panel that its trigger shows and hides. | [collapsible.md](collapsible.md) |
| Combobox | An input that filters a list of options to choose from. | [combobox.md](combobox.md) |
| Context Menu | A menu that opens at the pointer on a right-click or a long press. | [context-menu.md](context-menu.md) |
| Date Field | A date typed or stepped one segment at a time, in the locale's order. | [date-field.md](date-field.md) |
| Date Picker | A date field with a calendar in a popup, behind one value. | [date-picker.md](date-picker.md) |
| Date Range Picker | Two date fields with a range calendar in a popup, behind one range. | [date-range-picker.md](date-range-picker.md) |
| Dialog | A popup that opens on top of the entire page. | [dialog.md](dialog.md) |
| Drawer | A panel that slides in from an edge of the screen and can be swiped away. | [drawer.md](drawer.md) |
| Field | Labels a control, describes it, validates it and shows its errors. | [field.md](field.md) |
| Fieldset | A native fieldset that groups fields under a legend and disables them together. | [fieldset.md](fieldset.md) |
| File Upload | Choosing files through the browser's picker or by dropping them, with a list of what was chosen. | [file-upload.md](file-upload.md) |
| Form | A native form that validates its fields, waits for the server and shows the errors it returns. | [form.md](form.md) |
| Input | A native text input that works with Field. | [input.md](input.md) |
| Listbox | An always-visible list of options to select one or several from. | [listbox.md](listbox.md) |
| Menu | A list of actions in a popup, opened from a button and driven from the keyboard. | [menu.md](menu.md) |
| Menubar | A row of menus, as at the top of a desktop application. | [menubar.md](menubar.md) |
| Meter | A measurement within a known range, such as disk usage or a battery level. | [meter.md](meter.md) |
| Navigation Menu | A site's main links, with panels of more links that open from it. | [navigation-menu.md](navigation-menu.md) |
| Number Field | A text input for numbers, with buttons and a scrub area to step the value. | [number-field.md](number-field.md) |
| OTP Field | A one-time code entered one character per slot. | [otp-field.md](otp-field.md) |
| Pagination | Previous and next, numbered pages and ellipses, for moving through a long list. | [pagination.md](pagination.md) |
| Popover | An accessible popup anchored to a button. | [popover.md](popover.md) |
| Preview Card | A card that previews what a link points to while the link is hovered or focused. | [preview-card.md](preview-card.md) |
| Progress | Shows how far a task that takes a while has got. | [progress.md](progress.md) |
| Radio | A set of native radios of which one is checked. | [radio.md](radio.md) |
| Scroll Area | A native scroll container with scrollbars you draw yourself. | [scroll-area.md](scroll-area.md) |
| Select | A button that opens a list of options to choose a value from. | [select.md](select.md) |
| Separator | A line that divides content, horizontally or vertically. | [separator.md](separator.md) |
| Slider | A range input with any number of thumbs that you can style. | [slider.md](slider.md) |
| Sortable | A list whose items can be reordered by drag and drop, with the pointer or the keyboard. | [sortable.md](sortable.md) |
| Splitter | Panels separated by bars that resize them, with a pointer or the keyboard. | [splitter.md](splitter.md) |
| Switch | A native checkbox with the switch role, for a setting that is on or off. | [switch.md](switch.md) |
| Table | A data table on a native table element: sorting, filtering, selection, paging, column sizing and grouping, with TanStack Table keeping the state. | [table.md](table.md) |
| Table of Contents | A list of links to a document's sections that marks the one being read. | [table-of-contents.md](table-of-contents.md) |
| Tabs | A set of panels on the same page, one shown at a time. | [tabs.md](tabs.md) |
| Tags Input | A text input that turns what is typed into a list of removable tags. | [tags-input.md](tags-input.md) |
| Time Field | A time of day typed or stepped one segment at a time, in the locale's hour cycle. | [time-field.md](time-field.md) |
| Time Picker | A time field with a popup of hours, minutes and AM/PM to choose from. | [time-picker.md](time-picker.md) |
| Time Range Picker | A start and an end time, each with its own picker, in one group. | [time-range-picker.md](time-range-picker.md) |
| Toast | Short messages that appear without taking focus and go away by themselves. | [toast.md](toast.md) |
| Toggle | A button that is either pressed or not. | [toggle.md](toggle.md) |
| Toggle Group | A set of toggles that share one state. | [toggle-group.md](toggle-group.md) |
| Toolbar | A row of buttons and controls that is one stop for the Tab key. | [toolbar.md](toolbar.md) |
| Tooltip | A short label that appears when a button is hovered or focused. | [tooltip.md](tooltip.md) |
